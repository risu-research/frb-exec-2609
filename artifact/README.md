# Integrity staging v1

This branch is an internal execution-integrity staging surface. It is not a release, not a citation target, and not scientific authority.

Version 1 intentionally does not run measurements. Its only job is to keep the carrier fail-closed: repository guard files must remain present, scientific sources are treated as immutable, and no completed first-authority result may be replaced by this branch.

A later execution package may add exact frozen sources and result records only under a separately locked manifest. Until then, this branch must remain timing-disabled.
